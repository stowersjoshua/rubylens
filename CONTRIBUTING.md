# Contributing

Humans and AI agents follow the same rules, so they live in one place: **[AGENTS.md](AGENTS.md)**.

The short version:

1. Read [docs/intent.md](docs/intent.md).
2. Run `scripts/setup.sh` once.
3. For translation changes, write a golden case first ([docs/spec/translation.md](docs/spec/translation.md)).
4. Run `scripts/check.sh` before committing (`--full` after emitter changes).
5. Commit to `master`, with no AI attribution.
